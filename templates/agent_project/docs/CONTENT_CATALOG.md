# Optional authored content catalog

Use only when a finite roster of content or domain definitions helps this project. During setup
remove this document and references if it adds no value; do not create a catalog of every class.

| Content | State | Owning feature | Behavior / rationale / plan |
| --- | --- | --- | --- |

States: Proposed, Approved, Implemented, Cut.
An agent can select or refine Proposed entries in the consuming feature plan without separate
pre-planning approval. Plan generation alone does not approve implementation. A user's request
to implement the plan authorizes its stated in-scope selections; record that reference when
changing to Approved. Mark Implemented after the content exists and required verification passes.
Routine tuning can change with reasons; core product scope changes need user direction.
