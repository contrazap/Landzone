# Architecture evolution

Record material decisions when actual requirements establish or change an important boundary.
Do not manufacture refactors or reconstruct historical reasons without evidence. CODE_GUIDE.md
is the current implementation map; completed plans contain detailed verification results.

## Decision entry template

### YYYY-MM-DD - F##/D## - Decision title

- Before: Concrete prior design and relevant files.
- Pressure: Requirement or observed limitation that justifies action now.
- Decision: Chosen ownership, interface or representation.
- Alternative: Plausible rejected approach and reason.
- Behavior: What is preserved and what intentionally changes.
- Evidence: Actual verification and owning plan links.
- Tradeoffs/debt: Known costs and remaining limits.
- Study links: Current code guide section and actual files.
